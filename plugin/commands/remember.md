Report what memory currently holds for this project, using the reMem MCP tools.

1. Call `beliefs` to list what is held, with confidence.
2. For anything that looks wrong, doubtful, or out of date, call `why` on it and

3. Summarise in three parts, in this order:
   - what memory is confident about
   - what it holds weakly, or that has decayed
   - anything superseded, with the value it replaced

Be plain about gaps. If nothing is held for this project, say so and mention
that beliefs form when a session ends, rather than filling the space with
guesses.
